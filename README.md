# news-image-20261126

A one-page newspaper front, "THE WORLD TODAY", summing up the world news of Thursday, 26 November 2026 in a single 1024×1024 image. Seven stories lead the page, from Neuralink's FDA trial approval to burning tankers in the Strait of Hormuz, each with a flat vector illustration, and a strip of four briefs runs along the bottom. The image is drawn from code with Pillow (`render.py`), and `main.py` copies the finished `entry.png` to the output directory.
